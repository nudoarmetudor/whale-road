# Whale Road

An original browser trading-and-sailing game set in the Viking age. Static site, no build
step, plays on desktop and phone. Work in progress.

- `docs/CONTRACT.md` — architecture, file ownership, shared ids and module interfaces.
- `docs/FEATURES.md` — the feature checklist and coverage.

Map coastlines: Natural Earth 1:50m (public domain), via `tools/build_map.py`.
